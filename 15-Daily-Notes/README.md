# 📅 15 — Daily Notes

> Consistency beats intensity. Show up every day.

## Purpose
Daily learning logs are proof of consistency — they show recruiters a committed learner. Each note captures what was studied, what was understood, and what questions remain.

## File Naming Convention

```
YYYY-MM-DD-topic.md

Examples:
2024-01-15-soc-fundamentals.md
2024-01-16-wireshark-intro.md
2024-01-17-splunk-queries.md
```
