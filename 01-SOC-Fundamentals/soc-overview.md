# SOC Overview

## What is a Security Operations Center?

A **Security Operations Center (SOC)** is a centralized team of security professionals responsible for:
- Continuously monitoring IT infrastructure for security threats
- Detecting, analyzing, and responding to cybersecurity incidents
- Maintaining security tools and technologies
- Ensuring compliance with security policies

## SOC Functions

| Function | Description |
|----------|-------------|
| **Monitor** | 24/7 monitoring of networks, endpoints, logs |
| **Detect** | Identify anomalies, threats, and policy violations |
| **Analyze** | Investigate alerts to determine legitimacy |
| **Respond** | Contain, eradicate, and recover from incidents |
| **Report** | Document incidents and provide metrics to management |

## SOC Tiers

| Tier | Role | Responsibilities |
|------|------|-----------------|
| L1 | Alert Analyst | Triage alerts, basic investigation, escalation |
| L2 | Incident Responder | Deep investigation, containment |
| L3 | Threat Hunter | Proactive hunting, advanced analysis |
| L4 | SOC Manager | Strategy, metrics, team leadership |

## Alert Lifecycle

```
1. Raw log generated by endpoint/network device
2. Log forwarded to SIEM
3. SIEM correlation rule fires → Alert created
4. L1 analyst receives alert in queue
5. L1 triages: Is it a TP or FP?
   ├── FP → Document, tune rule, close
   └── TP → Investigate, escalate to L2 if needed
6. Incident Response process begins (if confirmed incident)
7. Post-incident report and lessons learned
```
