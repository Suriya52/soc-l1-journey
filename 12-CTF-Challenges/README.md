## Writeup Structure
Each CTF folder must follow this format:
```
C01-Challenge-Name/
├── README.md          # Challenge description + summary
├── walkthrough.md     # Detailed solution steps
├── screenshots/       # Evidence screenshots
├── artifacts/         # IOCs, scripts, extracted files
└── lessons-learned.md # Key takeaways
```
