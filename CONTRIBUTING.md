# Contributing to This Repository

This is a personal learning portfolio, but if you've found it helpful and want to suggest improvements:

## How to Contribute

1. **Fork** this repository
2. **Create a branch** (`git checkout -b improvement/your-idea`)
3. **Make changes** — fix typos, add resources, improve explanations
4. **Commit** with a clear message (`docs: fix typo in MITRE tactics guide`)
5. **Open a Pull Request** with a description of your changes

## What's Welcome

- ✅ Typo and grammar fixes
- ✅ Additional resources to the Resources section
- ✅ Better explanations of complex topics
- ✅ New cheat sheet content

## Not Accepted

- ❌ Offensive security content
- ❌ Actual malware samples or exploit code
- ❌ Personal data or credentials

Thank you for helping make this a better resource for the community! 🛡️
