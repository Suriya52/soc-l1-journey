# 📋 Templates

Ready-to-use templates for all documentation in this repository.

| Template | Use For | File |
|----------|---------|------|
| Daily Learning Log | Daily study notes | [daily-log-template.md](./daily-log-template.md) |
| Weekly Report | Sunday progress summaries | [weekly-report-template.md](./weekly-report-template.md) |
| Lab Report | TryHackMe / home lab writeups | [lab-report-template.md](./lab-report-template.md) |
| Incident Analysis Report | IR documentation | [incident-report-template.md](./incident-report-template.md) |
| Threat Hunting Report | Hunting documentation | [threat-hunting-report-template.md](./threat-hunting-report-template.md) |

## How to Use

1. Copy the template file to the relevant folder
2. Rename with the correct naming convention
3. Fill in every section — even if brief
4. Commit with a descriptive message: `docs: add day 14 learning log`
